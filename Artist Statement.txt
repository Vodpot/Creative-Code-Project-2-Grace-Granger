	Effective stereograms require a lot of visual noise to function best. To achieve this, I utilized the random function to allow 6 different shapes to be generated each in a unique grid. The grid’s number of shapes along both the x and the y axis are uniquely randomized, however the physical space the grid takes up is fixed to ensure each grid fills the entire 800 x 550 pixel sketch. Due to issues with what I now know is Lua’s “seed” for a random function, rather than allow the code to choose a shape using just the random function, I utilized the Fisher-Yates method of shuffling variables in an array (per the suggestion of my father, who is a coder, however I did the research into the method and how to implement it in Lua specifically). In Lua, it is coded as a for-loop. It’s semi-random, however it allows the shapes to be chosen more evenly (the code would routinely select only two shapes when I had only the random function). Additionally, random() was also used for the size of the shapes, though there was a constraint to prevent them from getting too large, and of course random() was utilized in both the color and opacity of each generated grid of shapes.
	The generated shape grids are capable of only choosing between Fluorescent Pink and Yellow, because both the background and the overlaid asset image (the part to actually be focused on in the stereogram) were Riso blue. To ensure that the asset image is neither too hidden nor too visible, the alpha values are only allowed to be between 40 and 70. Each grid has its own unique combination of size, color, and opacity, however, allowing countless combinations of the Riso blue, Fluorescent pink, and Yellow as each grid piles on top of the other in the grid’s for-loop.
	During the in-class critique, none of the other members in my group knew what a stereogram was, and were unable to get the trick to work in the short time we had. Because of this, I chose to keep the stereogram drawings more simple and a little more obvious, so it would be easier for people to pick up the trick to enjoy the work. I kept to simple shapes I’m fond of doodling; smiles, clovers, hearts, etc.
